# 운명의 한판 토너먼트

HTML, CSS, Vanilla JavaScript, HTML5 Canvas만으로 만든 정적 8비트 토너먼트 웹앱입니다.

본문 글꼴은 가독성이 좋은 오픈소스 **Pretendard Variable**을 로컬 파일로 포함합니다. 폰트는 SIL Open Font License 1.1로 배포되며 전문은 `fonts/OFL.txt`에서 확인할 수 있습니다.

## 캐릭터 에셋

`assets/characters/`에는 프로젝트용으로 새로 제작한 투명 PNG 스프라이트 시트가 포함됩니다.

- `clown-spritesheet.png`: IDLE / JUGGLING / SURPRISED / CELEBRATION
- `human-v1/`: 16종 사람 캐릭터(8스타일 × 2외형), 캐릭터별 걷기 4프레임 / 앉아서 울기 4프레임 / 대기·승리 4프레임
- 동일 캐릭터의 중복에는 12가지 의상 팔레트를 자동 분산합니다. 피부와 머리 색은 유지합니다.

캐릭터는 기존 게임 캐릭터·로고·고유 아이템을 복제하지 않은 오리지널 디자인입니다. 등록 시 가장 적게 사용된 캐릭터가 자동 배정되며 수동 변경 버튼은 없습니다. 캐릭터와 색상은 URL에 저장되어 새로고침·공유·다시 보기에서도 유지됩니다. 192명을 초과하면 동일 캐릭터·색상 조합의 재사용이 필요하며 균등하게 분산합니다.

제작 프롬프트와 프레임 구성, 검수 방법은 `dev-tools/HUMAN-CHARACTERS.md`에 기록되어 있습니다. 기존 동물·트레이너 에셋은 보관하지만 현재 화면에는 새 사람 캐릭터를 사용합니다.

`assets/backgrounds/`에는 같은 픽셀 렌더링 규칙으로 제작한 장면 에셋이 포함됩니다.

- `draw-stage.png`: 삐에로 추첨 무대
- `drumroll-curtain.png`: 공유 결과의 두구두구 공개 장면
- `champion-arena.png`: 스크롤 없는 최종 우승 경기장

## 실행

`index.html`을 브라우저에서 직접 열면 됩니다. 별도 설치, 빌드, 서버가 필요하지 않습니다.

등록 화면을 새 탭이나 새 페이지로 열면 확정된 노을 바다 정지 시안 기반의 약 5초 2D 오프닝이 다시 재생됩니다. 수평선·해안은 고정하고 수면·반사광·구름만 움직인 뒤 `운명의 한판` 타이틀에서 등록 화면으로 이어집니다. 한글 타이틀은 기존 로컬 Pretendard를 낮은 해상도 격자에 래스터화해 선명한 픽셀 테두리로 표시합니다. 우측 상단 `건너뛰기` 또는 Escape로 즉시 닫을 수 있습니다. 새로고침, 뒤로/앞으로가기, 진행 중 대회·공유 URL, reduced motion 설정에서는 생략합니다. 탭 간에 공유되는 재생 기록은 사용하지 않으므로 이전에 인트로를 본 브라우저도 새 탭에서는 재생하며, 저장이 차단된 환경에서도 새로고침 생략은 유지됩니다.

개발 확인용 `?intro=1`은 등록 URL에서만 강제 재생합니다. 대회·공유 링크와 reduced motion 설정은 이 옵션보다 우선합니다. 로딩이 1.8초를 넘거나 이미지·WebGL을 사용할 수 없으면 등록 화면으로 바로 넘어갑니다. 타이틀을 먼저 보여주어 긴 검은 로딩 화면을 피합니다. 종료·건너뛰기·탭 숨김·페이지 이탈 시 프레임 루프, GPU 리소스, 이벤트를 정리합니다. 외부 CDN이나 영상 플레이어는 필요하지 않습니다.

시안 원본, 제작 프롬프트와 구현·검수 기록은 `dev-tools/SUNSET-INTRO.md`, 실제 배경은 `assets/intro/sunset-v1/`에 있습니다. 이전 궁수 인트로 제작 에셋은 보관하지만 요청하거나 재생하지 않습니다. 추첨·대결·계단·결과 공개 애니메이션은 그대로 유지합니다.

## 사용 방법

1. 토너먼트 정보와 참가자를 입력합니다. (4명 이상 권장)
2. `랜덤 대진 생성`을 누르고 추첨 애니메이션을 봅니다.
3. 화면에 크게 표시되는 초기 1대1 경기의 승자를 선택합니다.
4. 승자조에서는 승자를, 패자조에서는 패자를 선택합니다. 선택 즉시 다음 1대1 경기로 넘어갑니다.
5. 예선 → 승자조 → 패자조 → 최종 결과가 각각 독립된 게임 화면으로 진행됩니다.
6. 최종 1위와 최하위가 모두 정해지면 계단 세리머니가 재생되고 결과 공유 화면으로 전환됩니다.
7. 결과 화면의 `엔딩 캐스트`에서 승리 수, 진출 단계, 최초 등록 순서로 정렬된 전체 참가자를 확인할 수 있습니다.

## 시안 연결 장면

- 추첨: `IDLE → JUGGLING → SURPRISED → CELEBRATION` 스프라이트와 3색 공 낙하, 플래시, 흔들림, 이름 공개
- 경기: 자동 배정된 사람 캐릭터를 좌측 상단과 우측 하단에 배치한 1대1 전투 화면
- 대진: 승자조 blue/gold, 패자조 red/purple HUD와 점등되는 전체 대진 경로
- 최종: 두 참가자의 계단 이동, 최하위의 코믹한 추락, 우승자의 중앙 스테이지 승리 포즈
- 결과: 중앙 우승자, 우승자 근처의 최하위, 폭죽, 반복 앉아서 울기·승리 프레임, 영화 엔딩 스타일 참가자 순위

## 상태와 공유

- 진행 상태는 UTF-8 안전 Base64 URL 형식으로 주소에 저장됩니다.
- `?mode=tournament&data=...` 주소를 새로고침하면 동일한 대진을 복원합니다.
- `?share=...` 주소는 최종 결과 전용 화면을 바로 표시합니다.
- 서버나 외부 API, 외부 이미지, CDN을 사용하지 않습니다.

> 매우 많은 참가자를 등록하면 모든 데이터가 URL에 포함되므로 브라우저의 주소 길이 제한에 영향을 받을 수 있습니다.
